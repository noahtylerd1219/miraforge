MIRAFORGE — EASIEST SETUP

1. Make a free account at github.com
2. Create a NEW PUBLIC repository named MiraForge.
3. Upload the CONTENTS of this folder to the repository.
4. Open Actions.
5. Choose: Build MiraForge VST3 (Windows)
6. Click Run workflow -> Run workflow.
7. Wait for the green checkmark.
8. Open the completed run.
9. Under Artifacts, download MiraForge-Windows-VST3.
10. Extract it.
11. Copy MiraForge.vst3 to:
    C:\Program Files\Common Files\VST3
12. In FL Studio: Options -> Manage plugins -> Find installed plugins.
13. Search MiraForge and load it.

You do NOT need to install Visual Studio, CMake, or JUCE for this method.
